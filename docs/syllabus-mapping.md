# Syllabus Mapping

## Unit 1: Fundamentals of Operating Systems
- **Linux & CLI**: Handled by the real Linux Agent running and collecting data.
- **Shell scripting**: Covered in `scripts/system_monitor.sh`, `scripts/process_monitor.sh`, and `scripts/security_check.sh`.
- **System administration automation**: Automated system telemetry extraction and API reporting.

## Unit 2: Process & Scheduling
- **Process states & PCB concept**: Demonstrated through the Process Monitor dashboard, showcasing PID, State, Threads, Memory, and CPU.
- **CPU scheduling**: Interactive "OS Learning Module" simulating FCFS, SJF, SRTF, and Priority algorithms visually via Gantt charts.

## Unit 3: Thread Monitor & Synchronization (Planned Scope)
- Mutex/Semaphore visualization and deadlock analyzer will be introduced in Phase 14+.
